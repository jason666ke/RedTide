# 说明文档

## 任务

将前序任务中对未来3天9个水质要素预测得到的序列作为输入，输出对这3天是否发生赤潮的检测结果

## 项目文件RedTide_detection

服务器路径：/root/lhq/RedTide_detection

核心文件夹：detection和data_preprocess

+ detection: 检测模型代码
+ data_preprocess：数据预处理代码

具体文件功能，在github仓库，Anomaly_detection分支下的README.md文件中有说明

数据文件夹：data_final和results

+ data_final：模型输入数据集，只需要输入9个特征即可，**不需要时间戳，且为NPY文件**
  + 12个站点文件夹+1个全站点文件夹
  + 训练集命名train.npy，测试集命名test.npy和test_label.npy
  + 若要进行没有标签的预测，则需要将文件命名为**predict.npy**，且**参数is_training设置为0**
+ results：无标签检测结果，例如检测大鹏湾下沙站点2021-2022年共729天的赤潮发生情况结果为dpwxs.csv，内容为长度是729的01序列，**无时间戳**

## 脚本文件run.sh

```shell
#!/bin/bash

for dir in ../data_final/*/; do
    PREFIX=$(basename "$dir")
    MODEL_ID="${PREFIX}"
    ROOT_PATH="../data_final/${PREFIX}"
    OUTPUT_PATH="../results/${PREFIX}.csv"

    echo "Processing folder: $PREFIX"
    echo "MODEL_ID: $MODEL_ID"
    echo "ROOT_PATH: $ROOT_PATH"
    echo "OUTPUT_PATH: $OUTPUT_PATH"
    
    CUDA_VISIBLE_DEVICES=0 python -u run.py \
    --is_training 1 \
    --root_path "$ROOT_PATH" \
    --model_id "$MODEL_ID" \
    --output_path "$OUTPUT_PATH" \
    --model TimesNet \
    --data RedTide \
    --features M \
    --seq_len 24 \
    --pred_len 0 \
    --d_model 64 \
    --d_ff 64 \
    --e_layers 2 \
    --enc_in 9 \
    --c_out 9 \
    --top_k 3 \
    --anomaly_ratio 1 \
    --batch_size 64 \
    --train_epochs 1

  echo "-----------------------------------"
done
```

+ 循环输入文件夹data_final下各个子文件夹的内容
+ 变量PREFIX为对应检测站点的缩写，如dpwxs，all_stations等，checkpoint的命名也是以站点缩写开头
+ ROOT_PATH：输入的文件夹，**注意这里只用精确到文件夹**，例如要进行预测，存放路径为/path/to/dataset/predict.npy，那么ROOT_PATH=‘/path/to/dataset/'即可
+ OUTPUT_PATH：输出的检测结果，**注意这里要精确到文件名**，例如预测结果存放路径为/path/to/results/output.csv，那么OUTPUT_PATH=‘/path/to/results/output.csv/'
+ **无标签检测时参数is_training=0**
